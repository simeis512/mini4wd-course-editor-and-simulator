# マシンパーツの実データ調査（Issue #30）

調査日：2026-10-25（日本時間）。対象：[Issue #30](https://github.com/simeis512/mini4wd-course-editor-and-simulator/issues/30)。

公式製品を加工せずに使うストック向けの基礎データを104行、加工後のオープン向け参考実測を1行、別々のCSVに収録した。代表的な製品の調査であり、全製品の網羅や実機の測定を完了したものではない。寸法や公称性能は集まったが、シミュレーターに必要な無負荷回転数・停止トルク・摩擦係数・取付座標などは追加測定が必要。

[カタログを使った追加調査](machine-parts-catalog.md)では、公式ダウンロードページを起点に56行を追加した。カタログの版と読取範囲、製品ページとの照合、条件付き適合も記録した。

[部品の抽象化と取付けモデルの設計案](machine-assembly.md)では、品番別の原データから性能タイプへまとめる方針、ステーの穴による接続、ねじ・スペーサー・マスダン・スタビの組立を整理した。収集した全品番を、そのまま独立した選択肢として実装する方針ではない。

2026-10-27受領の[Deep Research資料の照合](machine-research-review.md)では、追加の設定候補と、公式規則・実測による裏付けが必要な記述を整理した。添付レポートの数値をそのまま実測データに追加していない。

[公式ページの自動収集・分類・抽出案](machine-data-collection.md)には、通常のスクレイピング、GPT-6 Luna、Decisions／Responses APIの分担と評価方法を記録した。こちらは未実装の提案。

## クラスを分ける基準

調査依頼に従い、未加工のキット・パーツを `stock/`、ペラタイヤなどの加工後の値を `open/` に分ける。未加工の製品はオープンでも使えるので、オープンのマシンは `stock/` の基礎データを参照し、加工した部分だけ `open/` の別レコードにする。加工後の重量・径・性能を元製品の値に上書きしない。

規則の基準はタミヤの[ストッククラス・レギュレーション](https://www.tamiya.com/japan/mini4wd/regulation_stockclass.html)（2026年版2、5月11日改定・6月1日施行）と[公認競技会規則](https://www.tamiya.com/japan/mini4wd/regulation.html)（2026年1月5日の改訂・特別ルールを掲載）。大会固有の指定は別途扱う。

| 対象 | ストック向けの扱い | オープン向けの扱い |
| --- | --- | --- |
| 純正タイヤ・ホイール | 未加工の製品値。24mm製品も含む | 未加工なら共通データを参照 |
| タイヤのカット・切削 | 対象外 | 加工後の径・幅・重量を別測定 |
| シャーシの切削・肉抜き | 対象外 | 加工内容・重量・剛性などを別記録 |
| ダッシュ系モーター | ストックでも使用可能。クラス・大会の指定を確認 | 「高回転だからオープン専用」と分類しない |
| マスダンパー・スライドダンパー | 規則で認められる可動と取付けは使用可能 | 加工や独自機構の値は別記録 |
| ボディ、皿ビス加工、ホイールのシャフト貫通、ブレーキスポンジのカット | 公式規則には許容される加工もある | 許容加工まで一律にオープン専用とはしない |

「未加工パーツの表にある」ことは、任意の組合せでストックに出場できることを意味しない。説明書どおりのギヤの組合せ、干渉回避に必要なシャーシ加工の有無、取付位置なども確認する。例えばタイヤ製品の装着のためにシャーシを削れば、その組合せをストック用とは扱えない。

## データの場所と読み方

CSVはUTF-8、先頭行が列名。空欄は「今回の出典から確認できていない値」であり、0ではない。数値のある欄にだけ `evidence_status` が適用される。`manufacturer_spec` はメーカー公表値、`external_measurement` は第三者が自身の測定として公開した値。こちらでの実測は実施していない。

行数は製品数でもサンプル数でもない。例えば15459のウエイト形状を2行、15492のスポンジ厚みを3行に分けている。ギヤも製品と比率ごとに分け、`id` で識別する。品番別の数を数える場合は `item_no` を重複除去する。異なる形状・材質・測定条件の値を平均して「クラス標準値」にしない。

[適合関係7行](machine-parts/fitment.csv)と[カタログ出典台帳6行](machine-parts/sources.csv)は部品の行数に含めない。追加列の意味は[カタログ追加調査](machine-parts-catalog.md)に記載。

各行に `source_url` と `checked_on` を付けた。`checked_on` は閲覧日で、測定日や製造日ではない。訂正のある製品は `correction_url`、仕様変更のある製品は `spec_revision` も参照する。URLの存在は販売在庫の保証ではない。

### 列と単位

- 長さは `*_mm`、質量は `*_g`、電圧は `*_v`、電流は `*_a`、容量は `*_mAh`。モーターの負荷トルクは `*_mNm`（mN·m）、停止トルクは `stall_torque_Nm`（N·m）。
- 回転数はr/min。`load_rpm_min/max` は推奨負荷トルク時、`free_rpm` は無負荷時。両者を交換しない。
- `single` は片軸、`dual` は両軸。`listed_chassis` などの `|` は複数値の区切り。対応欄は掲載内容であり、取付条件まで判定するプログラムではない。
- シャーシの `reference_*` はメーカー掲載の構成例。`reference_gear_ratios` はその構成例の比率で、装着できる全ギヤ比の一覧ではない。`front_tread_mm/rear_tread_mm` は前後を分け、出典が単一トレッド幅を示す場合は同値を記録した。
- ローラーの `mass_basis=pair` は2個の合計質量。`mass_approximate=true` と電池の `cell_mass_approximate=true` は概数。マスダンパーの `weight_mass_g` はウエイト1個で、ビス等を含むセット総重量ではない。
- タイヤの `tyre_outer_diameter_mm` はタイヤ外径。裸のホイール径 `wheel_outer_diameter_mm` や接地幅とは別。スポンジの `sheet_*` は素材シート寸法で、切り出したブレーキの接触面積ではない。
- ローラーの `centre_*`、ダンパーの `mount_*` は、今後実機の取付位置を記録する欄。原点は前後車軸の中点の路面への投影、xは左、yは路面から上、zは前。今回の値は空欄。スクエアウエイトの寸法欄は32×8×8mmの形状を表し、搭載姿勢を表さない。

## オープン向け：加工後データを別集計

[ミニ四ファンの加工・測定報告](https://miniyonfan.com/peratire-create/)（記事表示日2024-06-04）から、作者が作成したペラタイヤ1組の径を参考記録として収録した。公式製品の公称値ではない。

| 対象 | 出典の測定結果 | 採用範囲 |
| --- | --- | --- |
| 切削したタイヤ4本・1組 | 外径23.88〜23.93mm、作者報告の概数約23.90mm | `open/modified-tyres.csv`、参考値のみ |

記事の公開日は測定日とは区別する。元品番・裸のホイール径・幅・重量・摩擦・反発の値は今回確定できないため空欄。範囲の幅0.05mmを計器精度や標準偏差として解釈しない。1組しかなく、オープンクラス全般の分布や平均値は計算しない。別品番の24mm純正タイヤと径が近くても、同じ物性とは扱わない。

今後は加工個体ごとに次の値を追加する。未確認の「定番サイズ」や仮の係数は実データに混ぜない。

| 加工・機構 | 元製品と分けて収集する値 | 現時点 |
| --- | --- | --- |
| ペラ・ハーフ・段付きタイヤ | 元品番、装着ホイール、各輪の外径・幅・重量、接地形状、真円度、材質、測定荷重 | 上記1組の外径のみ |
| シャーシ切削・フレキ等 | 加工図、組立後重量、可動量、ばね定数、減衰、ストッパー位置、重心 | 未採集 |
| 可動バンパー・ボディ連動の制振機構 | 支点、質量、可動範囲、摩擦、復元力、ローラーの移動量 | 未採集 |
| 加工したブレーキ・ステー | 加工前後の厚みと形状、装着高さ、接触面積、摩擦・圧縮特性 | 未採集 |

オープンでも公認規則の寸法・材質・モーター等の制約は残る。タイヤの形状変更は規定内で可能だが、表面材質の変更やホイールの接地は認められない。クラス別データに収録しただけで車検適合済みとはしない。

## 現行実装への影響と測定の優先順位

調査対象の実装：[machine-spec.ts](../src/physics/machine-spec.ts)。今回のCSVは調査資料として保存し、走行用の定数への反映は追加測定・モデル変更の段階で行う。

| 現行項目 | 調査で判明した注意点 | 次の作業 |
| --- | --- | --- |
| `motor.freeRpm` / `stallTorque` | 公称の負荷回転数・推奨負荷トルクとは別。ノーマル12,000rpm、停止トルク0.0035N·mの裏付けは今回確定できない | 電圧・温度・個体・慣らし状態を揃えて無負荷回転数と複数負荷点を測る |
| `mass` / `size` | 0.13kgの仮マシン、車体箱、ガイドの構成例の重量・外形は異なる対象 | 完成車総重量と車体形状、部品別重量を実測。電池の二重加算を避ける |
| `tyreRadius` / `wheelbase` / `tread` / `clearance` | スーパーIIの掲載構成は大径タイヤ。26mmの現行仮マシンと同じ構成ではない。前後トレッド差もある | まず1台の未加工キットを品番・構成ごとに測定 |
| `rollers` | 105mmは規則上限。13mm・高さ12mm・現在の前後位置がキット実測という根拠は未確認 | 径と取付穴・高さ・スラスト角・中心座標を記録 |
| `efficiency` / `grip` / `rollerFriction` / `rollerRestitution` | 現在の0.7 / 1 / 0.01 / 0.2は今回の公式仕様から確定できない | 駆動損失、路面別摩擦、着地・衝突を別実験で測る |
| マスダンパー・ブレーキ・電池 | 現行 `MachineSpec` に個別の動特性がない | #32の反映時に、可動体・接触形状・電圧低下の表現を検討 |

単位変換は、mm→mを1/1000、g→kgを1/1000、mN·m→N·mを1/1000。`gearRatio` はモーター回転数/車輪回転数。速度の計算にはタイヤ外径を使い、裸のホイール径を使わない。

モーターの線形モデル `T(n) = T_stall × (1 - n / n_free)` を校正するには、同条件の測定点が必要。公表範囲の端点だけから直線を当てたり、推奨負荷トルクを一律に何倍かして停止トルクとする値は、この実データ集には採用しない。

優先する測定は、(1) 未加工キット1台の構成・全重量・足回り・ローラー座標、(2) 同車の電池負荷電圧とモーターの特性、(3) 路面・フェンス別の抵抗と着地、(4) ストックの追加パーツ、(5) 加工後オープン個体の順。これはモデル校正の提案で、測定済みの結果ではない。

追加レコードにはクラス、元品番、加工内容、個体ID、測定日・測定者、計器・分解能、電圧、温度、荷重・接触面、繰返し数、測定前の状態、出典を残す。クラスと条件が一致したものだけを集計する。

Issue #30の公開資料調査として利用できる状態。カタログを起点とする追加調査を含むが、ホイール単体径、各パーツ重量、取付座標、動特性、加工個体の測定が残るため、全ての物理パラメーターを確定したとは扱わない。
