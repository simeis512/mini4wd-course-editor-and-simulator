## 一次資料で確認した境界

公式の[ストッククラス規則・Q&A](https://www.tamiya.com/japan/mini4wd/regulation_stockclass.html)（2026年版2、5月11日改定・6月1日施行）と[公認競技会規則](https://www.tamiya.com/japan/mini4wd/regulation.html)を再確認した。

- ストックでも指定のモーター交換、ボールベアリング、カーボン、純正のマスダンパー・スライドダンパー等は扱える。「ストックはノーマルモーターだけ」とはしない。
- オープン相当の通常公認規則にも、寸法・部品・加工等の制約が残る。ローラーのリング移植や異径部品の合体、電池受金具のハンダ付け等が一括解禁されるわけではない。
- ストックの禁止範囲、プレートの固定、接触し得る部品の固定と許容可動の条件は、部品単体の使用可否に加えて組立全体で確認する必要がある。
- 摩耗ローラーについて公式Q&Aは「極端に小さくなったもの」と車検員の判断を示す。確認した規則には、一律の「1mm以上摩耗」という数値基準はない。

禁止範囲の正確な立体形状は公式の図も含めて別途定義する。今回の照合だけで穴座標や禁止領域を数値化できたとは扱わない。一般規則の取付規制範囲と、ストックで追加される禁止範囲も区別する。

## 取り込む設定項目と抽象化

| 項目 | 取り込み方 | 物理・データ側で保つもの |
| --- | --- | --- |
| 四輪のタイヤ・ホイール | 通常は前後や左右をまとめて選び、必要なら各輪を個別設定 | 径・幅・材質・オフセット・回転慣性・取付方向。前後だけの2値に情報を縮めない |
| ボディ・固定ウェイト・電池 | 代表タイプと実際の取付先を選ぶ。可動マスダンとは区別 | 質量と位置・姿勢、形状、慣性。全装備重量・重心を部品から導出 |
| ブレーキ・スキッド部品・アンダーガード | 材質・外形・厚みと取付けを設定 | 接触面・取付姿勢・前後位置。摩擦・反発は未測定なら未確定 |
| ローラーとスラスト | 部品形状と取付軸の姿勢から配置 | 壁接触形状、リング・テーパー、軸受抵抗。角度だけで成功率を増減しない |
| マスダン・スライドダンパー | 直動・回転等の機構と上下限・支点を設定 | 可動質量、軸・支点、可動範囲、接触。固定部品との違い |
| オープンの加工機構 | 機構の型と代表設定をプリセット化。加工個体の原データは分離 | 接続トポロジー・自由度・ストッパー・復元力・減衰など。名称だけから係数を生成しない |

四輪個別設定や新しい候補項目を記録することは、全ての設定UIや物理機構を今回実装することを意味しない。ねじ・穴・1.5mm刻みのスペーサー、マスダンの空ける区間、湯飲みスタビの両取付けについては、先のユーザー方針を維持する。

## 編集・規則・物理の責務

編集側は実物に沿った「部品と接続」を保存し、規則側は規則ID・版・出典に基づいて組立・加工履歴を検査する。物理側は同じ組立から質量・重心・慣性、駆動、接触、機構を生成する。同じ組立・物性なら、クラス選択だけで走行性能を変えない。

規則の判定は、条件を満たす／満たさない／未確認・主催者判断が必要、を区別する。分類・抽出AIが高い確信度を返したことだけで車検適合を確定しない。編集画面で候補を絞ることと、保存された組立全体の検証も別に行う。

初期の車体1剛体という範囲を維持し、固定装備の質量配置・四輪設定・接触部品・組立検証を優先する。たわみ、多軸バンパー、提灯、フレキ、キャッチャーダンパー等は、抽象化した機構プリセットの候補として記録し、測定と実装を段階的に進める。パーツ名・加工名の数だけ通常画面のスライダーを増やさない。
