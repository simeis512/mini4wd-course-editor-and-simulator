# マシン部品の抽象化と取付けモデル（Issue #25 設計案）

更新日：2026-10-27（日本時間）。[Issue #25](https://github.com/simeis512/mini4wd-course-editor-and-simulator/issues/25)、[実データ調査 #30](machine-parts.md)、[編集画面 #31](https://github.com/simeis512/mini4wd-course-editor-and-simulator/issues/31)、[物理への反映 #32](https://github.com/simeis512/mini4wd-course-editor-and-simulator/issues/32)に関する設計メモ。

このチャットで示された「性能上の差異で部品を抽象化する」「ステー・プレートの形状と穴位置を重視する」「ねじとスペーサーによって配置を制約する」という方針を記録する。以下のデータ構造・計算方法・編集操作は、その方針を具体化する設計案であり、現行実装に追加済みの機能ではない。

Issue #25で先に合意した、最初は車体1剛体＋タイヤ4輪＋ローラー、たわみ等は後の段階で扱うという範囲を維持する。今回の組立構造を保存できることと、全ての機構の動特性を物理計算することは段階を分ける。

## 1. 部品の分類

| 部品 | 基本的に区別する値・形状 | 外観の設定 |
| --- | --- | --- |
| ホイール | 裸の径、幅、材質、オフセット、シャフトとの接続、質量・回転慣性 | 色、スポーク等の装飾形状 |
| タイヤ | 装着時の外径、幅、材質、断面・接地形状、質量、摩擦・反発の特性 | 色。材質の違いがある場合は物理側でも区別 |
| ローラー | 径、厚み、材質、ベアリングの有無・種類、軽量穴、ゴム等のリング、テーパー、上下2段構成 | 色、性能差として扱わない意匠 |
| シャーシ | 車軸位置、主要外形、厚み・下面、取付穴・座面、駆動系の接続、質量特性 | 色。材質差がある場合は別設定 |
| ステー・プレート | 機能上必要な輪郭、厚み、穴位置・穴径・穴種、材質、質量 | 色、印刷・装飾 |
| マスダンパー | 質量、外形、穴と軸の関係、取付機構、可動範囲 | 色 |
| スタビライザー | フェンスと接する外形・材質、取付部、内部の座面・空間 | 色 |
| ねじ・ナット・ワッシャー | 径、長さ、頭・座面・ナットの寸法、ねじ込み条件、質量 | 材質、色。材質は物理側にも反映 |
| スペーサー | 軸方向長さ、内外径、材質、質量、接触形状 | 色 |

同じ性能分類に複数の公式品番が対応してよい。品番・商品名は根拠資料への参照として保持し、選択画面で全ての色違い・意匠違いを独立した性能部品として並べる必要はない。ホイールとタイヤは別部品として扱い、タイヤ外径を裸のホイール径に使わない。

足回りは前左・前右・後左・後右の四輪ごとに保持する。通常操作では前後・左右を連動して選べるようにし、必要な場合だけ個別設定する。片側だけ異材質タイヤを使う構成や、ホイールの表裏・オフセットによる差を失わない。設定できる四輪の差と、走行モデルが反映できる差の範囲は区別する。

ボディ、固定ウェイト、電池も、質量と取付位置・姿勢を持つ部品として扱う。固定ウェイトと可動マスダンを区別し、全装備重量・重心・慣性は組立から導出する。ボディの軽量化を、重量変更と別の「安定性ボーナス」として二重計上しない。

同径・同幅・同材質でも、オフセットや質量・回転慣性に有意な差が確認できれば区別する。全商品を測定できない段階では代表値と出典・未確認状態を持ち、見た目だけから性能差を断定しない。

ローラーの軽量穴は、最初は「軽量タイプ」と質量・回転慣性で表現する案とする。穴の個数・面積を毎回入力させたり、一律の重量倍率を根拠なく適用したりしない。ゴム・テーパー・上下段はフェンスとの接触位置にも影響するため、接触形状と材質の違いを残す。ベアリングの有無だけで抵抗が確定するとは扱わない。

商品ごとのロゴ・印刷・装飾の複製を分類の目的に含めない。機能寸法を記録する設計方針と、参照資料や形状データの利用条件の確認は別に扱う。

## 2. ステー・プレート・シャーシの接続

形状は、実測等で確認できた輪郭・厚み・取付穴を可能な限り再現する。写真の縮尺だけから正確な穴位置を確定しない。現状の[ステー調査](machine-parts/stock/stays.csv)では穴ピッチが未確定で、測定が必要。

穴は単なる点ではなく、安定したID、部品内の座標、軸方向、穴径、貫通穴・ねじ穴・長穴・皿穴などの種類、表裏の座面を持つ。長穴は移動可能な範囲を持つ。固定パターンには対応する穴の組、許容される向き、必要な締結条件を定義する。

接続の判定は次を組み合わせる。

1. 固定パターンに必要な穴同士が、許された回転・表裏・位置で一致するか。
2. ねじ径、座面、板厚、ねじ込み深さが適合するか。
3. 他部品やタイヤと干渉しないか。接続として意図した重なり・接触は区別する。
4. 追加ステー・スペーサー等が必要か。
5. 不足する寸法があり、判定を保留すべきか。

判定結果は「取付可能」「条件付き」「取付不可」「情報不足」を区別する。商品ページに対応シャーシのタグがあることだけで、無加工・任意の位置への固定まで保証しない。1本止めでよいか、複数の穴を必要とするかは取付パターンごとに扱う。

部品の位置は、親部品・取付穴・取付面・接続姿勢から計算する。ねじ上の部品を独立した世界座標で自由に動かさない。複数の穴で同じプレートを留める場合も、そのプレートは1つの部品として管理する。

## 3. ねじに沿った組立

1つの取付けを「取付穴と面」「ねじ」「軸上の部品の順番」「固定条件」「可動区間」で表現する。

| 設定 | 意味 |
| --- | --- |
| 取付け先 | 親部品、穴ID、表側・裏側、座面 |
| ねじ | 種類、径、軸長、頭の形状、ねじ部の範囲 |
| ねじの向き | 頭が取付け先側／外側のどちらにあるか |
| 固定部品 | スペーサー、ワッシャー、ローラー、スタビ、ナット等の順序と保持方法 |
| 高さ調整 | 接続面または直前の部品からの、スペーサーで埋める隙間 |
| 可動部品 | マスダンパー等と、それを案内する軸・上下ストッパー |

ねじの向きと、取付面の法線に沿って部品を並べる方向は別の属性とする。ねじを逆向きにしただけでローラーが取付け面の反対側へ移動しない。

ねじの長さは、配置・保持に使える範囲を決める。プレート厚、座面、ワッシャー、ナット、固定先へのねじ込み分等を考慮して有効範囲を求める。ローラー高さはその範囲内で選び、マスダンの可動域はストッパー位置とウエイト寸法から求める。「ねじを長くすれば全ての部品が一律に上へ移動する」という計算にはしない。

短いねじに変更して積み重ねが収まらなくなった場合は、不成立箇所と必要長を示す。既存の配置を無断で削除・移動しない。ねじ先端側に固定するプリセットは、端部への追従をそのプリセットの動作として明示する。

## 4. 1.5mm刻みとスペーサーの自動配置

ユーザーの提案に従い、通常の高さ調整は1.5mm刻みとし、隙間にスペーサーを自動配置する。設定対象は「部品間のスペーサー長」で、世界座標やローラー中心高さの全てを1.5mmの整数倍に丸めるものではない。

例えば厚みが異なるローラーでは、同じスペーサー長でも中心高さが異なる。座面・ワッシャー・ナット・プレートの寸法もそれぞれ加算する。斜めのねじでは、この刻みをねじ軸に沿って適用する。

自動配置は材質・色を指定できる。部品数を減らすなどの一定の規則で、1.5 / 3 / 6 / 12mmから組み合わせる設計案とする。例えば4.5mmは3+1.5mm、7.5mmは6+1.5mm。選択結果を保存し、読み直すたびに別の組合せへ変えない。材質は質量等の入力にもなり、色は外観の設定とする。未確認の重量を色や材質名だけから実測値として作らない。

公式の[アルミスペーサー15473](https://www.tamiya.com/japan/products/15473/index.html)には、1.5 / 3 / 6 / **6.7** / 12mmがある。したがって1.5mm刻みは編集を簡単にするための抽象化であり、全ての実物の組合せを網羅するものではない。6.7mmは実データに残し、通常の自動配置には混ぜない。実物長を直接選ぶ拡張は将来の検討事項とする。

### マスダンの可動域

スペーサーで埋めてよい固定用の隙間と、マスダンが動くために空ける区間を明確に分ける。自動充填でマスダンを固定してしまわないようにする。

軸上の下側接触境界を `a`、上側接触境界を `b`、その姿勢でのウエイトの軸方向寸法を `h` とすると、単純な直動型の移動量は `b - a - h`。負なら組立不可、0なら可動量なしとして扱う。内部の段差・ワッシャー・他部品との干渉がある場合は、それらで実際の境界を狭める。

ストッパーの配置を編集するときは離散的な刻みを使っても、走行中のウエイトの動きは可動区間内の連続運動とする。ボールリンク等の回転型は別の自由度と接触境界が必要で、直動型の式をそのまま使わない。

## 5. ハイマウントチューブスタビの2つの取付け

ユーザーから示された次の2構成を、同じスタビ部品の組立プリセットとして扱う。

| プリセット | ねじ・保持部品の関係 |
| --- | --- |
| ねじ頭側に取り付ける | スタビをねじ頭側の座面・保持方法に合わせて配置する |
| 内部ロックナットで先端側に取り付ける | ねじ頭をシャーシ・ステー側へ向け、スタビ内部にロックナットを置いて先端側で保持する |

「ねじの向き」「スタビの開口の向き」「頭・ナットの保持座面」「内部ナット」を分けて持つ。円筒の見た目を反転するだけでは、内部ナットの位置や使用できるねじ長が表現できない。

[公式15528](https://www.tamiya.com/japan/products/15528/index.html)で確認できた外形は直径8mm・高さ10mm、材質はABS。内部の空間・段差・ナットとの接触寸法は今回確定できない。内部ロックナット構成はユーザーが示した実例を要求として記録し、全てのスタビ・ナットの組合せで装着可能と認定したものではない。

内部ナットはスタビの子部品として保持し、固定ねじとの接続にも関与させる。同じ場所にスタビとナットが見えても、意図した内部配置として判定する。ナットが空間に収まるか、座面が成立するか、ねじの有効長・掛かりが足りるかを検証する。内寸未確認なら「情報不足」とする。

プリセットを切り替えるときは、ローラー高さ等の既存設定を可能な限り保持して再検証する。逆付けという操作だけでストック／オープンを確定せず、部品・加工・固定方法と規則の条件を別に確認する。

## 6. データと画面の負担を抑える

データは「性能でまとめた部品定義」「接続に必要な形状・穴」「個々のマシンの組立」「色等の外観」「出典・検証状態」を分けて管理する。原資料は品番別に収集し、複数品番を同じ性能分類へ対応付ける。先に原データを統合して品番ごとの例外を消さない。

抽出処理では、材質・軽量穴・リング・テーパー・ベアリング・上下段・寸法・重量・取付条件を別項目として記録する。重さが同じでもフェンスに接する形状が違う場合など、分類を統合できない理由を残す。AIによる抽出や分類だけで未確認の穴座標や摩擦係数を補わない。

通常の編集は、(1) シャーシと取付穴、(2) ステーやプレート、(3) ローラー等の性能タイプ、(4) ねじ長と向き、(5) 高さ・可動量、(6) スペーサーの材質と色、の順に行う案とする。定番の組立をプリセットとして選び、必要な設定だけ変更できるようにする。

組立の保存では、安定した部品・穴ID、部品定義の版、接続関係、部品順序、ねじの向き、スペーサーの内訳、可動区間、外観を保持する。世界座標だけを保存して接続情報を失わない。将来のマシン保存形式はコースURLと区別し、部品定義の更新で過去の配置が変わらない方法を決める。

## 7. 物理モデルへの反映と段階

固定された車体・ステー・ねじ・スペーサー等は、最初は車体の剛体へまとめ、質量・重心・慣性と必要な接触形状に反映する。編集上の部品数だけ剛体を増やさない。スペーサー・ねじ頭・スタビはフェンスに接する可能性があるので、表示だけの飾りとして全て無視することもしない。

ローラーの回転抵抗等は初期モデルでは実効的な特性で扱い、マスダンの運動は #32 で対応する自由度・接触を追加する。初期段階で表現できない機構は、設定できる範囲と走行へ反映済みの範囲を区別する。

ブレーキ、アンダーガード、スキッド部品、露出するビス頭は、取付位置・姿勢・接触形状と物性から挙動を計算する。「ブレーキあり」「皿ビス未加工」などのフラグだけで、接触していない場面に減速・姿勢補正を与えない。スポンジ厚・貼付形状と、地上高や路面への接触は別の値とする。

組立・編集データはmm単位、上が+Y、前が+Z、左が+Xで統一し、物理計算へ渡す境界でSI単位へ変換する。外部資料の軸名をそのまま持ち込まない。スライドやマスダンの移動方向は、世界の鉛直方向に固定せず取付軸から求める。

規則の検査と物理への変換は別の処理とする。同一の組立・物性ならストック／オープンの選択だけで挙動を変えない。規則の版・出典・未確認条件を保持し、ストックの禁止範囲や許容可動も組立として検査する。幾何や規則の解釈が未確定な場合を、一律の適合・不適合や未公表の数値閾値に置き換えない。

実装は、穴と固定部品の接続→ねじ上の積層とスペーサー生成→直動マスダンの上下限→スタビの両プリセット→走行モデルへの反映、を基本の順序とする。幾何の詳細なCAD拘束解析や、ねじ山・締付け・全てのたわみの計算は初期範囲に含めない。

実装時の確認対象には、穴の不一致、表裏・斜め軸、複数穴での固定、短いねじ、異なる部品厚、1.5mm刻みの隙間、可動域への誤充填、上下限の干渉、スタビ内部ナット、反転後のねじ長不足、保存・再読込の一致を含める。これは将来の検証項目であり、現時点で組立機能の動作確認を終えたという意味ではない。

## 8. 添付調査との照合

2026-10-27に受領したChatGPT・GeminiのDeep Research資料について、[照合メモ](machine-research-review.md)に採用候補と未確認事項をまとめた。加工名のON/OFFから根拠のない性能倍率・成功率を生成せず、部品の形状・物性・接続・自由度に分解する方針を維持する。
