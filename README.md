# ミニ四駆コース作成シミュレーター

ジャパンカップジュニアサーキット（JCJC）のパーツを組み合わせて 3 レーンのコースを作り、3D や AR（WebXR）で確認できるようにする。
さらに、自分のマシンのカスタムを再現して物理演算でシミュレートできるようにする。

## 技術スタック

- TypeScript + Vite
- Three.js（3D 表示、WebXR による AR）
- Rapier（`@dimforge/rapier3d-compat`、物理演算）
- Vitest（テスト）

## 開発

```sh
npm install
npm run dev        # 開発サーバー（LAN 公開。スマホから AR 確認用）
npm test           # テスト
npm run build      # 型チェック + ビルド
```

WebXR の AR は HTTPS（または localhost）でのみ動作するため、開発サーバーは自己署名証明書の HTTPS で起動する。
スマホからは `npm run dev` の表示する Network の URL（`https://192.168.x.x:5173/` など、**https** で始まるもの）を開く。
初回は「この接続ではプライバシーが保護されません」などの警告が出るので、「詳細設定」→「アクセスする」で進む。
AR は Android の Chrome（ARCore 対応端末）で動く。iPhone の Safari は WebXR の AR に対応していない。

## 使い方（コースエディタ）

- 2D（上から見た図）で編集し、3D で立体表示を確認する。AR は 3D 表示の下のボタンから（対応端末のみ）
  - AR ではスマホを床に向けると青い輪が出る。床をタップするとコースがそこに置かれる（床を見つけられない端末では足元の少し前に置く）
  - 置く場所を選んでいる間は、輪が触れた床に白い点を残す。奥行きに対応した端末では、見えているものまでの距離を色で重ねる（近い＝赤、遠い＝青。「奥行き」ボタンで消せる）
  - 奥行きに対応した端末では、手や家具など手前にある実物の後ろにコースが隠れる（オクルージョン。「隠れ」ボタンで切り替え。境目は粗い）
  - 置いた後は指 1 本のドラッグで床の上を動かし、2 本指のひねりで指の間の床を中心に回す。⟲／⟳ で 15° ずつ回す、「大きさ」で実寸 → 1/5 → 1/10 → 1/20 を切り替える、「置き直す」で場所を選び直す
- オレンジの矢印（開いた口）をタップ → パーツを選ぶとつながる。続けて選ぶと先へ伸びていく
- ピースをタップして選択 → 色の変更、反転（カーブの左右切り替え）、削除。削除しても先のピースはその場に残る
- ドラッグで移動、ホイール／ピンチで拡大縮小。2D は 2 本指でひねるか右ボタンでドラッグすると回せる（左上の「向き」で 15° ずつ回す・元に戻すこともできる）。Ctrl+Z / Ctrl+Y、Delete、F（反転）も使える
- コースは URL（`#c=...`）に自動で保存される。「URLをコピー」で共有、JSON の書き出し／読み込みも可能
- 「QRコード」の「作成」タブでコースの URL を QR コードにして大きく表示する。デザインはチェッカーフラッグ・トリコロール（どちらも「ミニ四駆コース」の見出し付き。QR コード本体と余白は白黒のまま）・シンプルから選べる。印刷サイズ（幅 3/5/8/12cm）を選んで PNG（300dpi）・SVG で保存でき、下に文字（コース名など）を添えられる。1 マスが 0.5mm（仮）を下回るサイズでは読みにくいと警告する（保存はできる）。「読み込み」タブでは、QR コードの画像をドロップするか、枠を押して画像を選ぶとコースを開ける。スマホ・タブレットでは枠を押すと下からシートが出て「カメラで読み取る」「ギャラリーから選ぶ」を選べる（PC はそのままファイル選択）。「カメラで読み取る」はシートの中にカメラの映像が開き、QR コードを映すとその場で読み取る（URL のアドレスは問わず、コースの部分だけを取り出し、正しいコースか確かめてから開く）
- 「保存」（Ctrl+S）でコースに名前を付けてこのブラウザの中（IndexedDB）に保存する。一度保存したコースは「保存」で上書きする。「保存一覧」から開く・名前を変える・削除する。サーバーには送らない
- 「画像で共有」で SNS に載せる画像（横 16:9・1920×1080 か 縦 9:16・1080×1920）を PNG で保存できる。コースの絵はエディタの今の表示（2D/3D、向きや拡大もそのまま）を使い、画面には画像の形の枠が出る（「枠に合わせる」でコース全体を枠に収める）。横にコース名・全長（全レーンを走り切る長さ）・大きさ（縦横）・ピース数・コースの QR コードを添える（それぞれ表示・非表示を選べる）
- 保存していない変更があるまま別のコースを開く（保存一覧・URL・QR コード・ファイルの読み込み）か「新規」を押すと、「保存してから開く／保存せずに開く／キャンセル」を選べる。保存していないコースなら名前もその場で付けられる。再読み込みしても保存の名前と「保存していない変更がある」ことは引き継ぐ
- 編集中のコースは自動でブラウザ内に残り、URL にコースが入っていない状態で次に開いたとき「前回の続きを開きますか」と聞く（名前付きの保存とは別枠）
- 起動するたびに「ブラウザの中だけで動き、サーバーには保存されない」ことを知らせる（「次回以降表示しない」で止められる）。右上の「i」から権利表示・ライセンス・リンクと、この案内をもう一度見られる
- 開いた口どうしが 10mm・3° 以内で向かい合うとループが閉じたとみなし、誤差を表示する
- 2D の左上で「高さで色分け」と、指定の高さ以上のピースだけを表示するフィルターを切り替えられる（ほかのピースは薄く表示され、選べない）
- 3D では、持ち上がった路面の下に支柱を自動で表示する（見た目だけ。下を別の路面が通る所には立てない）
- スロープを使わずに高さを変えるときは、つなぎ目（緑の印）を選んで「折れ角」（上り+）を、ピースを選んで「ねじれ」（右下がり+）を ± で調整する。目安の 3°（仮）を超えると警告する
- つなぎ目を選んで「この先 ○ ピースで ○mm 上げる」を使うと、折れ角とねじれを自動で配分して一定の勾配で持ち上げ、最後に水平へ戻す。カーブを重ねて自分の上を越える螺旋もこれで作れる
- つなぎ目を選んで「横ずれ ◀ ▶」でレーン単位でずらして接続できる（1 レーンでもつながっている所まで）（カーブで作るレーンチェンジなど）。重なったレーンだけがつながり、はみ出たレーンは行き止まりになる。ブリッジアプローチの下段・上段の口には普通のパーツもつなげる（右レーンだけのジャンプなど）。レーンチェンジの下部だけを「アンダーブリッジ D」（2 レーン）として単体で使える
- パーツ一覧の「自作ストレート」は、ピースごとに長さを 10〜540mm（1mm 単位）で決められる（店舗が長さ合わせに作るストレートの再現）。紫で表示し、名前に長さが付く。開いた口につないだとき、まっすぐ先の届く範囲に向かい合う口があれば、そこへ届く長さに自動で合わせてループを閉じる
- ピースを選んで「ウォッシュボード ＋5mm / ＋10mm」で路面に貼り、レーン（口 a から見て左・中・右）、レーンの中の位置（左寄せ・中央・右寄せ。説明書どおり既定は壁沿い）、位置（口 a の端から真ん中まで mm）を決める。形は細長い板（長さ 120・幅 49/55mm）で、上面は平らな斜面。進入側は薄い部分から段差なくなめらかに上り始め、離脱側で最も厚く（5/10mm）なり、両端はテープ用の薄い部分。「⇄」で向きを反転できる（2D では厚い端を太線で表示）。横位置で「左の壁に立てる／右の壁に立てる」を選ぶと、ボードを縦にしてレーンの壁に貼れる（タミヤ公式の TIPS。ローラーを押す練習用）。進入側の曲がり・薄い部分の寸法は未計測のため仮
- パーツ一覧の下の「置き物」から、スタート・ラップタイマー・床の置き物を置く（#56、#53）。2D/3D のどちらでも選んでドラッグで動かせ、URL にも保存される。AR でも表示される
  - スタート：START のステッカーを全レーンに貼る。選んだピースか、画面の中央に近いストレートの真ん中に置き、道に沿ってドラッグで動かす。「⇄ 向きを反転」で走り出す向きを変える。コースに 1 つ
  - ラップタイマー（15184）：スタートを置くと、すぐ先（150mm、仮）に自動で付く。その後はスタートと別に動かせる。左右どちらの壁の外に立てるかを選ぶと、その側のレーンの上に張り出す。計測は「覆っているレーンだけ（実物どおり）」か「どのレーンも」を選べる（シミュレーター用）。寸法は箱絵からの仮の値
  - ホース：床に置く外径 15mm（仮）のホース。最初は輪で置き、白い点をドラッグして形を変え、「点を足す／点を消す」「輪にする」で整える。長さを表示する
  - 段ボール箱：大・中・小（仮の寸法）。既定は横倒しで、開いた口（2D では明るい線）をコースに向けて置く。「口を上に」にもできる。Q / E で回す
  - 「床の置き物（ホース・箱）を表示」で表示を切り替えられる。コース欄に床の広さ（置き物込み）を出す
- 左下のコース欄に検証の結果を常に表示する。名前をクリックするとそのピースや口を選ぶ
  - 行き止まりのレーン（ずらした接続や幅の違う口で、つながらなかったレーン）。「意図的」にチェックすると警告が消える
  - 未接続の口の一覧。ジャンプ台などわざと開けている口は「意図的」にチェックすると警告が消え、灰色の矢印になる（URL にも保存）
  - ピース同士の重なり（赤い「!」）と、立体交差の下の高さ不足（黄色い「!」、マシン高＋余裕の目安 80mm・仮）
  - ホースや段ボール箱がコース（道と壁）・支え・ラップタイマー・ほかのホースや箱に当たっていないか（黄色い「!」）。高い所を通る道の下に置いた箱は、道より低ければ当たらない。触れているだけなら警告しない
  - レーン一巡：#1 のピースに入るところをスタートとして各レーンをたどり、次の周にどのレーンへ移るか、各レーンの 1 周の長さ、何周で全レーンを走るかと合計を出す。「走る向きを反転」で逆回りにできる
  - 購入リスト：使うパーツを色ごとに数え（レーンチェンジ中央部はオーバーブリッジ 2 枚とアンダーブリッジ）、買う商品（品番）と数（お得な基本セットを最優先で探し、レーンチェンジ拡張セットとカーブ 4 枚セットをまとめて買うなら基本セットに置き換える）、今の単品では手に入らないパーツ（旧グレーなど）、余るパーツを出す。持っている基本セットを選ぶと、その分を差し引く（選択はこのブラウザに保存）。自作ストレートは長さごとに別枠で出す。価格は考えない

## 構成

- `src/course/catalog.ts` パーツカタログ（中心線の区間・接続口・色バリエーション、付属物、URL 用のパーツ番号表）。寸法は mm、多くは推定値。パーツ定義の型は `part.ts`
- `src/course/attachments.ts` ウォッシュボードなど路面に貼る付属物の位置と形、編集
- `src/course/timing.ts` スタートとラップタイマーの位置と形、`stoppers.ts` 床のホースと段ボール箱、`props.ts` それらの選び方（どれがどこにあるか）、`props-mesh.ts` それらの 3D メッシュ、`blocks.ts` 箱形の部品の共通の形
- `src/course/shopping.ts` 購入リスト（使うパーツを商品の品番に割り当てる）
- `src/course/geometry.ts` 中心線のサンプリングと接続口のフレーム計算
- `src/course/profile.ts` ウェーブの横うねりやブリッジの高さなどの形の関数
- `src/course/course.ts` コースのデータ（連結グラフ）、配置計算、ループ閉じ判定
- `src/course/flex.ts` ジョイントの折れ角とピースのねじれ
- `src/course/raise.ts` 区間を ○mm 上げる（折れ角・ねじれの自動配分、螺旋）
- `src/course/model.ts` 実測モデルへの差し替えの口（メタデータの型と検査、形状ソースの切り替え）
- `src/course/edit.ts` 編集操作（追加・削除・反転・移動など）
- `src/course/joining.ts` 連結と分断、ドラッグ中に口を引き寄せる磁石
- `src/course/add.ts` パーツを口につなぐ・ドロップ先を選ぶ
- `src/course/codec.ts` コース ⇄ URL ハッシュ（バイナリ → deflate-raw → base64url）
- `src/course/height.ts` ピースの高さの範囲（階層フィルター）と支柱の位置
- `src/course/laps.ts` レーン一巡と各レーンの周長（検証）
- `src/course/clash.ts` ピース同士の重なりと立体交差の高さ（検証）、`stopper-contact.ts` ホース・箱がほかの物に当たっていないか
- `src/course/mesh.ts` 3D メッシュ生成（路面＋フェンスの掃引、支柱。シーンは m 単位）
- `src/editor/app.ts` エディタの状態と操作。`panels.ts` パネル表示、`checks.ts` コース欄（検証の結果）、`shopping.ts` コース欄の購入リスト、`attach.ts` ウォッシュボードの設定欄、`props.ts` 置き物（スタート・タイマー・ホース・箱）の追加と設定欄（2D の描き方は `props2d.ts`）、`drag.ts` ドラッグ操作、`share.ts` URL・ファイルでの受け渡し、`library.ts` ブラウザ内の保存と自動保存（IndexedDB は `store.ts`、名前や一覧の決め方は `src/course/saves.ts`）、`notice.ts` 起動時の案内と「i」の情報パネル、`levels.ts` 2D の高さ表示の設定、`history.ts` 元に戻す／やり直し
- `src/editor/view2d.ts` / `view3d.ts` 2D 編集ビュー、3D/AR ビュー（共通インターフェースは `view.ts`、AR の設置と操作は `ar.ts`（指の操作は `ar-gesture.ts`）、床の点は `ar-scan.ts`、奥行きの表示とオクルージョンは `ar-depth.ts`、その置き方の計算は `ar-pose.ts`、2D の道の外形は `outline2d.ts`）
- `src/physics/` Rapier の物理ワールド（シミュレーター用、未接続）
